# Оформление и поведение

## Цвета и шрифты

Цвета заданы в `:root` в `styles.css`:

| Переменная | Цвет | Назначение |
|---|---|---|
| `--ink` | `#0B0E14` | Фон страницы |
| `--panel` | `#151A22` | Панели |
| `--paper` | `#EDF0F5` | Основной текст |
| `--muted` | `#8E98A8` | Вторичный текст |
| `--accent` | `#5B8CFF` | Ссылки и кнопки |
| `--accent-hover` | `#7BA4FF` | Кнопки при наведении |

Заголовки используют Golos Text, основной текст использует Manrope. Браузер загружает оба шрифта из Google Fonts; запасной вариант: системный sans-serif.

## Первый экран

На высоком экране `.screen` остаётся на месте, пока пользователь прокручивает `.film`. JavaScript меняет прозрачность и вертикальное смещение трёх кадров. Неактивным кадрам выставляет `inert` и `aria-hidden`.

При высоте окна до 600 px или при ширине до 600 px и высоте до 700 px сайт показывает кадры друг за другом. Тот же вариант работает без JavaScript и при `prefers-reduced-motion`.

JavaScript обновляет кадры через `requestAnimationFrame`. `IntersectionObserver` отслеживает видимость сцены, `ResizeObserver` пересчитывает её размеры. Сайт не перехватывает события колеса мыши и касания.

## Эффекты

- Ссылки с `data-magnetic` смещаются за указателем в пределах 4 px по горизонтали и 3 px по вертикали. На сенсорном экране и при уменьшении движения эффект отключён.
- Фоновый градиент движется в течение пяти секунд видимости сцены. На экранах шириной до 600 px, при уменьшении движения и в режиме принудительных цветов он неподвижен.
- Кнопка «Звук» включает три синусоидальных тона через Web Audio. При уходе со сцены или скрытии вкладки JavaScript выключает звук. Для повторного включения нужно нажать кнопку.
- Видео демонстрации содержит запись работы бота. Пользователь управляет воспроизведением через стандартные элементы браузера.

## Доступность

В разметке есть ссылка перехода к проектам, навигация, подписи кнопок и FAQ на `details`/`summary`. CSS задаёт видимый фокус, отключает анимации при `prefers-reduced-motion` и учитывает `forced-colors`.

Эти меры не заменяют проверку клавиатурой, скринридером и аудит контраста. Порядок ручной проверки описан в [README.md](README.md).
